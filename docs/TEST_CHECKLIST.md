## 常见问题排查

### 问题 1: 图片上传失败
```bash
# 检查存储权限
chmod -R 775 storage
chown -R www-data:www-data storage
```

### 问题 2: 队列不执行
```bash
# 检查队列配置
cat .env | grep QUEUE_CONNECTION

# 手动运行队列
php artisan queue:work --tries=3
```

### 问题 3: 邮件发送失败
```bash
# 测试邮件配置
php artisan tinker
> Mail::raw('Test', function($msg) { $msg->to('test@example.com')->subject('Test'); });
```

### 问题 4: 数据库连接失败
```bash
# 检查数据库配置
cat .env | grep DB_

# 测试连接
php artisan migrate:status
```
